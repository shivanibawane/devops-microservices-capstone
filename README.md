# DevOps Capstone Project 1: Microservices CI/CD Pipeline
A production-grade, 8-stage CI/CD pipeline for a 3-tier E-commerce microservices application with quality gates and automated rollback.
## Architecture
- **Frontend Service**: Node.js / Express
- **Products Catalog Service**: Python / Flask
- **Cart Service**: Node.js / Express
- **CI/CD Orchestration**: Jenkins (Declarative Pipeline)
- **Security & Quality Gates**: SonarQube & Trivy
- **Configuration Management & Deployment**: Ansible
